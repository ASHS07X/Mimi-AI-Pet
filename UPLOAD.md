# Push to GitHub

The project is prepared for `https://github.com/ASHS07X/Mimi-AI-Pet`.

From this folder, after GitHub authentication is available, run:

```powershell
git push -u origin main
```

If you download the source bundle rather than using this local Git checkout, add the remote before pushing:

```powershell
git remote add origin https://github.com/ASHS07X/Mimi-AI-Pet.git
git push -u origin main
```
